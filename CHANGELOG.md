# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-13

### Added
- **Database Schema**: PostgreSQL database schema and migrations managed via Supabase.
- **RLS Policies**: Row-Level Security policies to protect team/workspace data privacy.
- **Real-time Engine**: Supabase broadcast and presence channel configurations.
- **OAuth Gateway**: GitHub OAuth configuration and session management.
- **Slack Bridge**: Deno Edge Functions for bi-directional message/thread synchronization.
- **Setup Suite**: Automated local Docker (self-hosted) and remote cloud database deployment scripts.
- **Documentation**: Initial developer collaboration guidelines and deployment guides.
